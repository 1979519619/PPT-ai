# 发布验收范围

自动回归检查覆盖密钥读取/加密保存、内存截图和录音、脱敏日志、输入限制、流式输出与麦克风清理。它们不能代替真实放映、硬件或课堂验收。

`fixtures/acceptance-deck.pptx` 是合成样张，保留早期 M0 文案；第 7、8 页的“多圈合并”描述已过时，当前实现和验收标准为每圈一张图、最多 5 张。样张没有因本次开源准备重新生成。

| 范围 | 检查内容 | 证据要求 |
|---|---|---|
| 安装/卸载 | 选择目录、启动、快捷方式、密钥加密保存、本地 ASR、正常退出、卸载清理 | 对实际安装器进行验证，记录版本及 SHA256 |
| WPS | 全屏出现、语音、确认取消、流式/公式、圈选冻结、圈外遮罩、多圈独立图片、焦点归还、停止/隐藏/退出 | WPS 实机逐项记录，不用源码推断代替 |
| PowerPoint | 全屏浮层、语音确认与回答、圈选及焦点恢复 | 仅关键冒烟；失败记录为兼容限制 |
| 教室机 | 安装、麦克风、本地识别、WPS 浮层截图、网络 | 教室设备实测；触屏/笔另列 |
| 长稳 | 一次连续 30 分钟使用 | 内存、进程、失败恢复及异常记录 |
| 课堂价值 | 3 次课，每次至少 5 次真实提问，0 核心中断 | 用户真实使用记录；同一堂课两次及以上核心中断则暂停加功能 |

当前本机安装验证结论不等于 WPS/PowerPoint 完整验收或教室机验证。首次正式课堂使用前应完成剩余阻塞项。
