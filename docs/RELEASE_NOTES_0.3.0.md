# PPT-AI Classroom 0.3.0（发布草稿）

Windows x64 课堂问答浮层：本机语音识别、确认发送、最多 5 区圈选、流式回答和公式显示。使用者需自行配置 DeepSeek API Key。

本版本采用 Apache-2.0 许可；第三方组件保留各自许可。录音、截屏和问答正文不由应用主动落盘；发送行为和第三方服务说明见 [隐私说明](../PRIVACY.md)。

**当前安装器未签名**，SignPath 申请尚未提交或获批。Code signing policy 见 [签名政策](../CODE_SIGNING.md)。公开发布前，应上传与相应 GitHub Actions 提交一致的安装器及 SHA256SUMS；不得把本地历史安装包冒充 CI 产物。

完整 WPS/PowerPoint、教室机、触屏、长稳和真实课堂验证仍需按 [验收范围](ACCEPTANCE.md) 完成。当前不承诺生产课堂可用性或 SmartScreen 放行。
