# 0.4.0-preview.1 最终修改与构建范围

日期：2026-11-05。依据用户 TXT 与最终只读报告处理现存问题，不实施报告第六节的新功能提案。

| 报告问题 | 本轮处理 |
|---|---|
| B-01 旧测试接口 | 更新为当前服务与请求接口，并保留纯模块边界用例；按用户要求不执行测试。 |
| H-01 缺 VC++ 运行库 | 构建前准备官方固定版本 x64 运行库，由安装器在目标电脑按需安装；本机仅下载准备，不安装它。 |
| H-02 安装目录素材 | 本机 50 个素材文件已完整迁到 E:\PPT-ai-assets，迁移时逐文件核对；安装器升级准备也保留旧 assets，卸载不递归删任意根目录文件或默认清除 Key 配置。 |
| H-03 残留子进程 | 安装前只针对本产品已确认安装路径下的主进程及识别/检测子进程收尾，不按通用 python/whisper 名称全局结束进程。 |
| M-01 识别行顺序 | 文字碎框按竖直重叠、相对字高与横向位置重建行，英文词间空格及邻近标点一起处理。 |
| M-02 代理/证书 | DeepSeek 使用 Electron net.fetch；本机音频使用直接回环连接，不走外部代理。 |
| M-03 端口身份 | 随机回环端口、随机请求前缀、监听 PID 与存活检查，不将任意监听程序视作本机语音服务。 |
| M-04 隐私页 | 生成 UTF-8 BOM、CRLF 的纯文本供 NSIS 页面使用。 |
| M-05 输入钩子 | 独立 STA 消息循环与事件输出，避免与慢 COM 查询共享消息处理线程。 |
| L-01—L-12 | 输出预算/长文提示、麦克风共享、恢复与退出提示、UTF-8 解码、加密配置备份/替换、Esc 不清空、会话权限、动态版本、Unicode 参数、快捷键及文档/输出版本同步。 |

安装目标为 Windows x64，教程面向 Win11；尚未进行希沃一体机测试。当前范围不含 Raw Input、新原生检测程序、安装预检仪表盘、Job Object 管理架构或其他未来功能。

执行顺序：完成必要修改与构建输入准备 → `[skip ci]` 提交 GitHub → 本地生成 NSIS 安装器 → 只记录构建完成及安装器文件大小/校验值。**不运行测试/语法检查，不拆开成品安装器，不安装或卸载复验。** 这些限制意味着不能宣称完成了干净设备上的功能或兼容性验证。
