# 0.4.0-internal.6 源码更新与最终审查

日期：2026-11-05。

本次更新仓库中的内部待测源码和文档。**即将进入安装包构建阶段，目前仍需完成前后端功能性及其他 Windows x64 设备兼容性的最终审查；本次没有生成或发布新版安装包。** 公开下载区现有 v0.3.0 安装器不代表本次源码版本。

## 本次累计功能

- 浮球、圈选、发送前确认、语音输入、停止/清除以及普通设置窗口。
- 每批最多五个矩形选区，中英互译先用本地 OCR 提取原文及位置，允许校字或按区选择图片翻译，一次批量请求取得译文。
- 使用真实文字排版、原文字高和本机空白检测决定下方放置；无空间、位置不可靠或溢出的段落保留在完整回答框。
- 透明文本框支持移动、四角拉伸、8–128 像素字号、黑/白/蓝、返回完整回答框。
- 放映编辑中第一次框外单击结束调整，随后恢复正常放映点击；也可使用“完成调整”或 Esc，悬停不自动显示边框。
- 可靠页码、保守操作保护与请求失效隔离；可用时以受支持的原生课件字号增强 OCR。
- 增加独立本地 OCR CPU 运行资源准备脚本和打包资源声明；模型、运行时、依赖、配置和日志不提交到源码仓库。
